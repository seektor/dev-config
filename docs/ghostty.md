# Ghostty

## Install

```bash
brew install --cask ghostty
brew install --cask font-fira-code-nerd-font
```

## Config

| Setting | Value |
|---------|-------|
| Font | FiraCode Nerd Font, size 16 |
| Theme | Catppuccin Mocha |
| `window-inherit-working-directory` | `false` (new windows always open in `$HOME`) |
